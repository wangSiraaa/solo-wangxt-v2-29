# 经纬组织设计台（Weave Studio）

浏览器内的单层织物组织设计工具：组织点阵、穿综、纹板、踏板顺序与织物预览保持实时一致。
纯前端实现，无任何后台接口。

## 技术栈

- **Vue 3 + TypeScript**：界面与响应式状态
- **Canvas**：四类网格编辑器与经纬交织预览
- **Web Worker**：组织图 → 穿综/纹板/踏板的约束反推计算（`src/workers/solver.worker.ts`）
- **Dexie（IndexedDB）**：本地工程存储，自动保存
- **Vitest**：核心算法单元测试

## 运行

```bash
npm install
npm run dev        # 开发
npm run test       # 核心算法测试
npm run typecheck  # 类型检查
npm run build      # 生产构建
```

## 数据模型与一致性

- **结构**：`threading`（每根经纱的综框号）+ `tieUp`（纹板：踏板×综框）+ `treadling`（每根纬纱的踏板号）
  唯一确定组织图 `pattern[y][x]`（`true` = 经组织点）。改任一方案，组织图由 `computed` 立即重算。
- **颜色**：`warpColors` / `weftColors` 与结构完全分开存储，仅用于预览渲染与导出色条。
- **组织图直接编辑**：画下的点先进入“未同步”状态，由 Worker 反推：
  - **唯一解**：直接应用（仅在综框/踏板编号置换意义下唯一，界面如实说明）；
  - **多解**：应用占用综框最少的规范解，并以警告说明还存在哪些等价方案；
  - **无解**：绝不编造数字——草稿保持不变，报告所需综框/踏板数，组织图保持“未同步”，
    可一键“调整为 N 页综并重试”或放弃修改。
- **撤销/重做**：所有编辑以事务为单位记录快照；一次拖动批量修改只产生一条记录，
  撤销即整体恢复事务前全部受影响数据。

## 反推原理

两根经纱能共用一页综，当且仅当它们的组织列完全相同；纬纱与踏板同理。
因此“不同列数”即所需综框数的充要条件——多解与无解的判定是精确的，不是启发式。

## 预设

- **平纹**：2 综 2 踏板
- **2/2 斜纹**：4 综 4 踏板
- **八枚缎纹（需 8 综）**：在综框不足时演示“无解”报告与一键扩容重试

## 导出

- **JSON**：完整工程（结构 + 颜色分开存放），可重新导入，导入前做严格校验；
- **意匠图 PNG**：穿综图 + 纹板图 + 组织图 + 踏板图四象限，标注经向（纵向）/纬向（横向）箭头与经纬色条；
- **预览 PNG**：织物交织效果图，画布上直接标有经向/纬向双箭头。

## 长浮线

浮长 ≥ 阈值（默认 5，可调）的经/纬浮线在组织图与预览中以橙色框高亮。
